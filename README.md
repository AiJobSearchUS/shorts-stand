# 🍋 Shorts Stand

**A local-AI pre-production studio for short-form video — powered by Lemonade.**

Type a topic. Get a complete production pack: 3 scroll-stopping hooks, a
timestamped script (voiceover + on-screen text + shot direction per beat),
clean voiceover narration, timed captions (SRT), and a title / description /
hashtags pack. Everything is generated by a model running **on your own
machine** via [Lemonade Server](https://github.com/lemonade-sdk/lemonade) —
no API keys, no per-token cost, no ideas leaving your laptop.

Built for the [AMD Lemonade Developer Challenge](https://www.amd.com/en/developer/resources/technical-articles/2026/join-the-lemonade-developer-challenge.html).

## Why

Creators making a video a day (or twenty) burn out on the blank page, not the
camera. Shorts Stand removes the pre-production bottleneck: hooks, structure,
and packaging in seconds, privately. Your niche, your voice, your hardware.

## How it works

```
  topic ──▶ Lemonade (localhost:13305) ──▶ production pack/
                                              ├─ script.md        (beats w/ timestamps, VO, TEXT, SHOT)
                                              ├─ voiceover.txt    (clean narration for TTS)
                                              ├─ captions.srt     (timed captions)
                                              ├─ metadata.json    (title, description, hashtags, pinned comment)
                                              └─ raw_model_output.md
```

Two LLM calls per pack: one creative pass (hooks + script + voiceover), one
packaging pass (metadata as JSON). The client speaks plain OpenAI-compatible
chat completions, so any Lemonade model works — pick by VRAM, not by vendor.

## Quickstart

1. Install Lemonade Server and start it:
   ```powershell
   lemonade serve
   lemonade pull Qwen3-8B-GGUF   # or any chat model you like
   ```
2. Clone this repo, no dependencies beyond Python 3.10+ (stdlib only):
   ```bash
   git clone <repo> && cd shorts-stand
   ```
3. Generate a pack:
   ```bash
   python -m shorts_stand.cli "5 side hustles with no money" \
       --niche "personal finance, beginners" --duration 45
   ```

### Configuration

| Env var            | Default                          | What it does              |
|--------------------|----------------------------------|---------------------------|
| `LEMONADE_BASE_URL`| `http://localhost:13305/api/v1`  | Model server endpoint     |
| `LEMONADE_MODEL`   | `Qwen3-8B`                       | Model name to request     |
| `LEMONADE_TIMEOUT` | `900`                            | Seconds per LLM call (raise on slow/CPU hosts) |

Flags `--base-url` / `--model` override the env vars. Point it at LM Studio,
Ollama, or vLLM and it just works — Lemonade is the default, not a lock-in.

## Web UI

A single-page UI (still stdlib-only — `http.server`, no npm, no frameworks):

```bash
python web.py            # http://127.0.0.1:8080
python web.py --port 8080
```

Uses the same `LEMONADE_BASE_URL` / `LEMONADE_MODEL` env vars as the CLI —
set `LEMONADE_MODEL` to the model you loaded in Lemonade (e.g.
`Qwen3-4B-Instruct-2507-GGUF`).

Enter a topic, niche, and duration → the page polls a background generation
job against your local Lemonade server, then renders hooks, the timestamped
script, voiceover, captions, and metadata with one-click downloads of every
pack file (`script.md`, `voiceover.txt`, `captions.srt`, `metadata.json`,
`raw_model_output.md`).

